# 安装与操作总指南

## 首次安装

已测试的解释器为 Python 3.12，支持 Windows 和 Linux。元数据允许 3.10 至 3.12，其他版本不宣称已测。使用独立虚拟环境；数值依赖固定为 JAX/jaxlib 0.4.38 与 NumPy 1.26.4。

```sh
git clone https://github.com/hl682/Crucibles_JAXMARL.git
cd Crucibles_JAXMARL
python -m venv .venv
```

在 Windows 运行 `.venv\Scripts\activate`，在 Linux 运行 `source .venv/bin/activate` 激活后执行：

```sh
python -m pip install -e .
crucibles smoke --game 225
crucibles play --game 225
```

也可以双击 `start.cmd`，或运行 `bash start.sh` 完成首次安装与启动。之后直接运行启动指令。每款说明书列出准确游戏键；早期四款使用独立的 `v1_000` 等标识。

## 建局与控制

保持终端开启，打开它打印的准确网址。公开网站提供保存的动图与说明书，实时游戏由本机运行。选择游戏和种子，点击 `Create session`；首次编译可能需要一分钟。

输入从零开始的角色编号，例如 `0,2,5-8`，选择主持人或受邀者，用 `Assign / take over` 分配；用 `Assign all roles` 可接管全部角色，没有人数上限。给每个角色选择合法指令，点 `Queue` 排队，再点 `Advance one joint step` 同时推进。

方向键或 WASD 为当前角色视角排队对应方向动作，空格推进时钟；无方向动作时用下拉框。掩码和阶段仍有效。未排队角色由未经训练的合法动作均匀采样策略操作。自动时钟按钮可持续推进，手动协调前可暂停。下一步前接管或释放不重置状态与回报，主持人控制时钟。

## 多人及局域网

用 `Create player invitation` 生成带权限链接，另一标签页或参与者打开后，由主持人分配另一组角色。邀请只发给参与者。其他电脑在同一可信局域网参与时运行：

```sh
crucibles play --game gi225 --bind 0.0.0.0
```

主持人先打开打印的可达局域网地址，再创建邀请，确保链接使用该地址。默认仅监听本机，不提供公网托管。端口占用时改用 `--port 8766`，不要结束其他进程。

## 视角、日志与结束

角色视角遵守原可见性；`Full-state debug` 是特权视角，开启会永久记入日志。预览使用此视角，不能直接作为分散策略输入。游戏与动图文字固定英文，说明书可切换语言。动图不证明任务已解出。

日志保存在 `local-runs`，记录动作、奖励、输入归属、接管与完整性链。人类成绩尚未独立核验。关闭会话保留日志并释放名额，最多四个并存会话限制编译内存。重启服务丢失内存会话，尚未实现会话断点恢复。

## 没有移动怎么办

确认分配角色、排队合法指令并推进时钟，再检查该款阶段、能量、距离、容量及伙伴同步输入。第一百三十四号游戏先经过六步拍卖，第一百九十六号先推进议会阶段。合法动作也可能没有有效产出。抽象游戏显示状态变化，不编造空间地图。
