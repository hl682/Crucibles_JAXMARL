## Objective and gameplay

Return both mission cases to the public western extraction point before alarm failure or H=112.

Lures and carrying noise redirect shared patrols and can expose nearby teammates; radio actions share actual local information; locksmith gate opening changes all roles future routes; object transfers change who must risk noisy movement.

- Extract both cases at the western exit. Alarm five ends the mission in failure.

- Only role 0 has the one-use tool for the central gate; north and south openings provide alternative routes.

- Lures consume one of three charges and emit strength six. Moving with a case emits four, radio opening three, unlocking five.

- Sound decays one per step and loses one per Manhattan cell. It penetrates walls by definition.

- Patrols retarget to the strongest audible source; ties use source index. Attention persists three ticks.

- Patrols move one cell toward a target with deterministic x-first then y fallback, respecting walls and the gate.

- A nearby source can expose a different crew member. All-wait silence reduces alarm only when nobody is exposed.

- Radios consume one of two charges and share live sender positions and nearby patrol/gate visibility for three ticks.

- Interact together to transfer a case to an adjacent empty-handed partner; floor pickup and extraction use distance one.

- Role views hide patrols, cases, gate state and sounds outside the declared visibility or hearing rules.

Ending: Both cases extracted, or shared alarm >=5. Natural completion takes precedence over horizon; any simultaneous success and failure indicators retain their specified reward contributions.

## What this game explores

Information, sensing & communication: Who knows a fact, when it was measured, and whether it was communicated are separate state variables. Test memory or communication using only the same role-visible evidence.

Joint transport & shared access: Positions, load geometry, occupancy and persistent access constrain whose action can succeed next. Distinguish physical handoff, shared controls and simultaneous force from a cosmetic cooperation label.

Survival, protection & rescue: Protection and repair alter another role's future feasible actions. Record losses, exposure, rescue and infrastructure as well as delivery; survival is determined by the actual kernel.

These are questions supported by rule structure, not observed learning effects.

## Reinforcement-learning integration

```python
import jax
from crucibles_jaxmarl import make

env = make("gi123")
key = jax.random.PRNGKey(0)
key, rk, ak, sk = jax.random.split(key, 4)
obs, state = jax.jit(env.reset)(rk)
actions = env.sample_actions(ak, state)
obs, state, rewards, dones, info = jax.jit(env.step_env)(sk, state, actions)
done = dones["__all__"]
```

Observations are float32 vectors of width 356; actions are scalar int32; masks have 8 entries. Supply all 3 roles each transition. Masked sampling is an engineering reference, not a trained learner.

`step_env` retains terminal data without reset. `step` performs outer autoreset and keeps terminal data in `info["raw_state"]` and `info["raw_observation"]`. Use `dones["__all__"]` for episode boundaries; separate completion, failure and time limit in analysis.

JIT or vmap equal identities and shapes. Split independent reset, policy and transition keys. Group different shapes explicitly; do not shrink the population or horizon. Host rendering stays outside training.
