# GI232 · Basalt Archipelago Rescue

Rescue 32 stranded residents while crews choose how to allocate finite basalt among local shelters, causeways and boat capacity.

## Identity and original contract

256 independently actionable roles; 20 discrete commands per role; 686 native observation columns per role; original horizon 896 steps. Declared per-step reward range: -2 to 3. Observation regime: `partially_observable`.

The objective, rewards, population, map and horizon remain original. A preview is not a success claim.

## Objective and gameplay

Rescue 32 stranded residents while crews choose how to allocate finite basalt among local shelters, causeways and boat capacity.

Nearby bracing enables another actor to take and move a stretcher; finite stone supports communal crossings or private protection; boat cargo displaces passenger capacity and gate state changes physical reachability.

- Move with actions 1–4; identical codes pilot a boat when an equipped pilot is aboard.

- Pick tools quarry stone. Hammer tools spend it on shelters or causeways; exchange tools and stone with adjacent workers.

- Causeways need level 2 and an open lift gate. Shoals are passable only during the low-tide half-cycle.

- A rescue-kit carrier needs another nearby actor choosing Brace to pick up or move a stretcher.

- Boats carry at most eight actors minus stone cargo; boarded actors follow the selected pilot's real movement.

- Ash grows every 32 steps. Hammer clearing takes three subsequent ticks; strong shelters protect nearby workers and routes.

- Bring a resident within one tile of any shelter and choose Deliver. All residents saved ends the episode.

- Role views expose local objects and four nearby actors. These rules and scene are authored; no replay has been executed.

Ending: Natural completion occurs exactly when all 32 resident saved flags are true. Otherwise H=896 truncates the ongoing world; no reward target is a release condition.

## What this game explores

Information, sensing & communication: Who knows a fact, when it was measured, and whether it was communicated are separate state variables. Test memory or communication using only the same role-visible evidence.

Joint transport & shared access: Positions, load geometry, occupancy and persistent access constrain whose action can succeed next. Distinguish physical handoff, shared controls and simultaneous force from a cosmetic cooperation label.

Survival, protection & rescue: Protection and repair alter another role's future feasible actions. Record losses, exposure, rescue and infrastructure as well as delivery; survival is determined by the actual kernel.

These are questions supported by rule structure, not observed learning effects.

## Reinforcement-learning integration

```python
import jax
from crucibles_jaxmarl import make

env = make("gi232")
key = jax.random.PRNGKey(0)
key, rk, ak, sk = jax.random.split(key, 4)
obs, state = jax.jit(env.reset)(rk)
actions = env.sample_actions(ak, state)
obs, state, rewards, dones, info = jax.jit(env.step_env)(sk, state, actions)
done = dones["__all__"]
```

Positions, load geometry, occupancy and persistent access constrain whose action can succeed next. Distinguish physical handoff, shared controls and simultaneous force from a cosmetic cooperation label.
