# GI007 · Cross-key lock with delayed messages

Each role sees a private binary target specifying the OTHER role's correct dial. Actions 0/1 set one's dial, 2/3 transmit a bit, and 4 build charge. Transmitted bits enter a wire and reach the partner's remembered inbox on the following transition. The observation reveals one's own outgoing bit in transit, not the partner's private target or dial. Charge levels, lock openings and jam state are public. Joint charge at least 0.8 triggers evaluation when unjammed. Matching both cross-targets opens the lock, clears communication and charge, and samples new private targets using the supplied key. An incorrect joint attempt clears charge and jams the lock for four transitions. Noncharging actions decay charge. Each role changes the other's joint opportunity and reward through persistent dial, charge and transmitted information. Reward is 0.8 for opening, -0.2 for a failed attempt, and 0.015 signaling cost when transmitting. Success and failure are exclusive, so reward stays within [-0.215,0.8]. Partial information and communication delay may support coordination but no learning effectiveness, eligibility or validation is claimed.

## Reinforcement-learning integration

```python
import jax
from crucibles_jaxmarl import make

env = make("gi007")
key = jax.random.PRNGKey(0)
key, rk, ak, sk = jax.random.split(key, 4)
obs, state = jax.jit(env.reset)(rk)
actions = env.sample_actions(ak, state)
obs, state, rewards, dones, info = jax.jit(env.step_env)(sk, state, actions)
done = dones["__all__"]
```

Observations are float32 vectors of width 16; actions are scalar int32; masks have 5 entries. Supply all 2 roles each transition. Masked sampling is an engineering reference, not a trained learner.

`step_env` retains terminal data without reset. `step` performs outer autoreset and keeps terminal data in `info["raw_state"]` and `info["raw_observation"]`. Use `dones["__all__"]` for episode boundaries; separate completion, failure and time limit in analysis.

JIT or vmap equal identities and shapes. Split independent reset, policy and transition keys. Group different shapes explicitly; do not shrink the population or horizon. Host rendering stays outside training.
