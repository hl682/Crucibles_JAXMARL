Methods, coverage, interpretation and source integrity
Budget completion is not proof of learning, task solution, statistical significance, or generalization.

Coverage is frozen to the 12 runs in the review receipt observed at 2026-11-01 06:05:31 UTC. Later files and runs do not enter this snapshot automatically. These fixed-learner baselines do not implement or validate the planned LLM/UED or meta-gradient method.

Returns use each game's own reward scale. Do not rank games or aggregate performance across games. Four evaluation seeds from one trained policy are not four independent training replications. Failures, negative results and missing event evidence remain visible.

How to read this snapshot

The learner is role-conditioned, parameter-shared IPPO with a feedforward policy and four frames of own-observation history. It uses native legal actions, native rewards without shaping, and no privileged critic. Evaluation uses stochastic legal-action sampling with the same independent seeds and native horizon for IPPO and the uniform-legal random baseline.

Every retained evaluation point is shown. The reported endpoint is the final budget checkpoint; evaluation scores were not used to choose a checkpoint. The mean native return averages across roles and evaluation episodes; the role vector is retained below because averaging can conceal opposing outcomes. The joint environment step count counts joint environment transitions across parallel environments, not individual agent actions.

The original cloud SVG and PNG files are copied byte for byte. Exact values and paired episode differences remain in the original JSONL. No local training or evaluation was performed to generate this page.
