# astra-d2-00049 — Delayed demand disclosure and irreversible mutual assembly

This parentless proposal combines a generic communication task with asynchronous commitment and perishable components. Its relationship to cooperative bit communication and complementary production is explicit. It is not asserted to be structurally unique, copied from a particular game, validated, eligible or learnable.

Each agent privately observes a binary requirement for the component that the other agent must supply. Actions are 0 wait, 1 stage a zero component, 2 stage a one component, 3 send one's actual private requirement, and 4 lock one's staged component. An unlocked component can be replaced. A locked component cannot be changed until the other agent also locks, when the two-part assembly is settled and both component slots clear. Locking an empty slot is a legal no-op. The episode clock continues across assemblies and terminates at 32 steps.

A send action creates a pending truthful message; it is delivered during the following transition. The public archive retains the delivered requirement until assembly settlement. The sender observes its pending-message indicator; the recipient sees the value only after delivery. Both staged values, locks and component ages are public. Each agent sees only its own current private requirement. A completed assembly samples independent fresh private requirements with the supplied step key and clears every old message, including pending ones, so old requirements cannot be used for the next assembly.

Observations 0..15 are time, own requirement, own/other staged values, own/other locks, own/other archived message values, own pending-message indicator, own/other component ages, own/other archive ages, completed-assembly count, own previous satisfaction result and previous joint-success indicator. A missing component or message is encoded as zero; binary values are encoded as one half and one.

Settlement pays each agent for whether the partner's component meets its requirement, with value multiplied by that component's age-dependent quality. Quality decreases to a floor of one quarter. Correct receipt pays 0.85 times quality; incorrect receipt pays -0.55 times quality. Joint correctness adds 0.1 to each agent. Writing, sending and newly locking cost 0.025, 0.01 and 0.01 respectively. The result is clipped to [-1,1]. Waiting can reduce either positive or negative settlement magnitude, which is a deliberate consequence of treating deterioration as reduced consequential value rather than an extra penalty.

The two decisions are causally coupled through each agent's contribution to the other's reward and through the requirement that both locks persist before settlement. Early locking can trap a wrong component; waiting permits disclosure but lowers component quality. Cooperation may require truthful messages and making a component valuable to the partner even though most direct payoff is determined by the partner's contribution. No claimed learning or performance result accompanies this source.
