# astra-d2-00070: Cross-pollination with delayed yield and a shared aquifer

This parentless proposal combines generic resource competition and reciprocal ecological assistance. Two independently planted crops can benefit from the other plot's incompatible variety, while same-variety pollen damages crop health. This is an abstract rule system, not a biological accuracy claim, a copied game, or a demonstrated new equivalence class.

Actions are 0 rest, 1 plant variety 0, 2 plant variety 1, 3 irrigate and 4 release pollen. Planting requires an empty plot and at least 0.20 nutrients; it consumes those nutrients and creates a crop with initial growth 0.05 and health determined by current nutrients. Existing crops grow each transition and automatically harvest when accumulated growth reaches 1.0. Irrigation speeds growth and consumes a common aquifer. Simultaneous requests share available water equally, with each request capped at 0.16. Water replenishes with the current shared weather. Rest replenishes private plot nutrients, while harvesting depletes them further.

Pollen release puts the emitting crop's variety in the other agent's next-state incoming-pollen field. On the following transition it changes an established receiver crop's health: different variety adds 0.22 and same variety subtracts 0.14, subject to [0, 1] clipping. An empty or newly planted plot does not use that incoming pollen. The packet then expires unless replaced by another release. Release also reduces the emitter's current growth increment by 0.07 and incurs an immediate cost. Emission can still occur on a harvesting transition. Thus helping a compatible partner can delay one's own harvest, while mismatched coordination can damage the partner's eventual return.

Each agent privately observes its own fixed variety preference, planted variety and crop health. Public signals include both nutrient reserves, growth, planted/empty indicators, previous actions and realized harvest values, together with weather and aquifer level. Incoming pollen reveals the emitted variety. Previous planting actions are public, so the partner's variety can be reconstructed from history; it is not claimed to remain secret. The other's fixed preference and health are not direct observation columns.

The 16 columns are clock; own/other nutrients; shared aquifer; current weather; own crop code; own growth; own health; own preference; incoming pollen code; other growth; other planted indicator; own/other preceding harvest value; own/other previous action. Crop and pollen code 0 denotes absent, 0.5 variety 0 and 1.0 variety 1.

A harvested crop returns 0.65 times health plus 0.15 if it matches the owner's preference. Utility subtracts 0.12 for successful planting, 0.035 times the fraction of a full irrigation ration, and 0.04 for pollen release. Reward is tanh(2 times utility), bounded in [-1, 1]. The shared water effect and the delayed pollen effect are separate routes by which either agent changes the other's prospects. Health and growth persist between actions, and unfinished crops at the 32-step horizon receive no forced salvage payout.
